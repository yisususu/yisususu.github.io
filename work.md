Selected projects from my work on databases and LLM inference infrastructure.

### MySQL contribution {#mysql}

At Alibaba Cloud, I worked on MySQL replication, production debugging, and reliability. I reported and contributed a patch for MySQL bug #110962: state retained after an `UPDATE` could cause later valid statements to warn or fail. The contribution is acknowledged in the MySQL 9.7.2 release notes.

[Bug report and patch](https://bugs.mysql.com/bug.php?id=110962) / [Official acknowledgement](https://dev.mysql.com/doc/relnotes/mysql/9.7/en/news-9-7-2.html)
